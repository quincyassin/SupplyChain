分单宝 - 使用说明
========================

【启动】
  双击 start.bat，或桌面/开始菜单快捷方式「分单宝」。
  浏览器会自动打开 http://localhost:8080
  优先使用系统默认浏览器；若 360 浏览器协议异常无法打开，将自动改用 360 安装路径启动。

【停止】
  双击 stop.bat；卸载前也会自动停止。

【数据位置】
  程序数据（数据库）：安装目录\data\db\
  Excel 导出文件：桌面\testData\

【备份】
  复制整个 data 文件夹即可备份订单与配置。

【升级】
  安装新版本时选择相同目录，保留 data 文件夹即可。
  安装程序会自动停止旧版本后再覆盖文件；安装完成后启动即可看到新版本。
  若界面仍异常，可先双击 stop.bat 再 start.bat，或浏览器 Ctrl+F5 硬刷新。

【日志】
  安装目录\logs\app.log

【端口占用】
  默认使用 8080 端口。若被占用，请联系技术支持修改配置。

【系统要求】
  Windows 10 / 11  64 位
